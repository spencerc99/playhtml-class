### Example: counting visits automatically on page load

Last week we peeked at a visit counter that bumps on page load. That works, but there's a timing catch: `onMount` runs when playhtml wires up the element locally — often **before** persisted data has finished loading. A write in plain `onMount` can get overwritten by the incoming saved value.

If you want auto-increment without a click, wait until the connection is ready:

```html
<div can-play id="visit-counter">0</div>
<script>
  const visitCounter = document.getElementById('visit-counter');

  visitCounter.defaultData = { visits: 0 };

  visitCounter.updateElement = ({ element, data }) => {
    element.textContent = data.visits;
  };

  visitCounter.onMount = ({ setData }) => {
    void playhtml.ready.then(() => {
      setData((data) => {
        data.visits += 1;
      });
    });
  };
</script>
```

For teaching and most projects, a click ("I'm here!") is simpler and avoids the race entirely.

### Example 2: listen for a shared custom event

So far our data has lived _on_ an element. Sometimes you instead want a one-shot signal that fires for everyone on the page at once — confetti, a sound, a flash — without storing anything. That's a custom event. You register a listener for an event type, and playhtml runs your `onEvent` whenever _anyone_ dispatches it:

```html
<script type="module">
  import { playhtml } from 'https://unpkg.com/playhtml';

  playhtml.init();

  playhtml.registerPlayEventListener('confetti', {
    onEvent: () => {
      console.log('confetti for everyone');
      // ...drop confetti, play a sound, flash the screen, etc.
    },
  });
</script>
```

### Example 3: connect it to a button

Dispatching the event is what triggers everyone's listener. Here we fire it when this visitor clicks a button:

```html
<button id="celebrate-btn">Celebrate</button>
<script type="module">
  import { playhtml } from 'https://unpkg.com/playhtml';

  playhtml.init();

  document.getElementById('celebrate-btn').addEventListener('click', () => {
    playhtml.dispatchPlayEvent({ type: 'confetti' });
  });
</script>
```

The click happens on one person's screen, but because `dispatchPlayEvent` sends the event through playhtml's shared infrastructure, the `confetti` listener from Example 2 runs on _every_ connected page. You can also pass data along with the event (`dispatchPlayEvent({ type: 'confetti', eventPayload: { color: 'gold' } })`) and read it in `onEvent`.
