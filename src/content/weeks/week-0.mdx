Hi everyone! This is Spencer and Munus writing to you _wink wink_. We are so excited to have you in the class, and can't wait to see what you will make.

Before we get started, we have kindly ask you to do a few things to get ready for the first session:

## Setup your computer

Download and setup the following softwares:

- [VS Code](https://code.visualstudio.com/) or another code editor of your choice. This is where you will write your code and build your site.
- [Google Chrome](https://www.google.com/chrome/) or anything uses Chromium (the engine) is the recommended browser for testing your site, but you can technically use any browser you like.
- [GitHub Desktop](https://desktop.github.com/) or another Git client of your choice. This is how you will use to push your code to GitHub to keep track of your work.
- Create an account on [GitHub](https://github.com/) if you don't have one already. This is where you will host your code and share it with us and your classmates.

## What's a space you want to re-create digitally?

We will be discussing [this article "Why the disappearance of digital third spaces matters" by Nuzhat Tahiya](https://www.thedailystar.net/star-youth/news/why-the-disappearance-digital-third-spaces-matters-4084946) in the first session, so please read it before class. While you're reading, we encourage you to think about a physical communal space you want to re-create digitally, and note the attributes, interactions, or elements that define that space. We will share this in class!
