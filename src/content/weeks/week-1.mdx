Intro to the class!

- This is a 5-week class where we will learn how to build communal web experiences using playHTML, an open-source library for designing communal web experiences by enhancing web elements with real-time, collaborative interactivity!

## Open Source, AI and Code Use Policy

Copying, pasting, and reusing code is a natural and valuable part of learning technology and programming. Often, the best way to learn is by modifying existing examples, experimenting with libraries, and building on others’ work. This collaborative spirit is at the heart of the open-source philosophy: we stand on the shoulders of giants. That said, there are important guidelines to ensure fairness, learning, and academic integrity:

1. Programming is a collaborative and creative process, and you are encouraged to help each other learn and grow. However, unless otherwise stated, all assignments and projects must represent your own individual work.
2. Always label borrowed code. If you use code from open-source projects, tutorials, online forums, libraries, or AI tools. Whether you copy it exactly or modify it, you must clearly acknowledge your sources. When in doubt, include comments at the top of your code specifying where the original code came from and how you adapted it.
3. You should be able to explain how any borrowed or adapted code works, including AI-generated code. This helps us better assess your learning and ensures that you’re actively engaging with the material, not just copying.
4. Do not submit someone else’s full project as your own. Reusing snippets or functions is allowed with credit, but turning in entire projects created by others is not permitted.
5. Respect licenses. When using open-source libraries or code, respect the terms of their licenses. Some may require attribution or have restrictions on commercial use.
6. You are encouraged to use AI tools and and external resources as part of your learning process. However, any AI-generated content included in your submission must be clearly disclosed and credited. You remain responsible for ensuring that the code works correctly and that you understand it fully.

The ultimate goal is to create something that evokes a feeling in other people! The things that best do this have a core handmade nature to them that expresses care and love towards the people you are designing for. AI-generated code can a really useful tool for overcoming technical inaccessibility and testing out ideas, but don't let it become a crutch for making something that matters.

A short guideline: if you are still coming up with the idea, try it out by hand, make the most lo-fi version you can, get a feel for what feels right. if you are running into difficult bugs, hard technical challenges that you don't understand, try asking AI for help and seeing how it can unblock your understanding and get you further towards the feeling you are chasing.

## The infrastructure we're using (playhtml)

We will be building our internet spaces on top of [playhtml](https://playhtml.fun/), an [open-source library](https://github.com/spencerc99/playhtml/) for making communal web experiences by enhancing web elements with real-time, collaborative interactivity!

**Expectation Setting:** playhtml is an indie, passion project. This means that you may encounter bugs, missing features, etc. Please report them to me as you find them! We'll be building this communal software together and ultimately, building the internet we want together :)

The focus of this class will be using the library to create your own collective space, but I welcome contributions to the core library and happy to discuss that as well if you feel inclined and inspired to do so.

At a high level, the library provides an open infrastructure (that Spencer hosts) that facilitates real-time state syncing and data persistence and a simple programming interface for managing data (which is core to making social interactions). What this means is that you can make things that save and accumulate over time (guestbooks, canvases, etc.), and have actions happen instantly for everyone on the page (live cursors, chat, etc.).

The goal of playHTML is to provide the infrastructure so that we can make a million tiny internets flourish to fill in the gap between huge social media platforms optimized for audience growth and expressive personal websites that have limited community space.

### Getting started with playHTML

The simplest way to use playHTML is to include it in your HTML file via a CDN link (CDN stands for Content Delivery Network, and it's a way to load libraries directly from the web without having to install them on your computer):

```html
<body>
  <style>
    #my-lamp {
      /* width & other styles */
      filter: brightness(0.55);
      transition: filter 0.3s ease;
    }

    #my-lamp.clicked {
      filter: brightness(1.2) saturate(1.6)

    import { playhtml } from 'https://unpkg.com/playhtml';

    playhtml.init();
```

### Quick Crashcourse on HTML/CSS

If you're new to HTML and CSS, here are some resources to get you started:

- [HTML Tutorial](https://www.w3schools.com/html/)
- [CSS Tutorial](https://www.w3schools.com/css/)

Basically HTML is the structure of your webpage, and CSS is the style. You can add attributes to your HTML elements to give them different properties, and you can use CSS to customize how they look.

HTML is a markup language that uses tags to define elements on a webpage. For example, `<button>` defines a button element, and you can add attributes like `id` or `class` to give it specific properties.

```html
<img id="my-lamp" can-toggle src="lamp.png" alt="lamp image" />
```

Only one thing can be the id of an element, but you can have multiple classes. In this example, we have a button element with an id of "my-lamp" and a class of "lamp".

CSS is a stylesheet language that describes how HTML elements should be displayed. You can use CSS to change the color, size, position, and many other aspects of your HTML elements. For example, you can use the `background` property to change the background color of an element, or the `transform` property to rotate or scale an element.

```css
.lamp {
  background: #6cd97e;
}

#my-lamp {
  color: white;
}
```

There are many other properties and attributes you can use in HTML and CSS, and you can combine them in creative ways to make your webpage look and behave the way you want!

### The built-in attributes

Usually if we want to make any element interactive, we would need to write some JavaScript code to add event listeners and update the state of the element. But with playHTML, you can simply add built-in attributes to your HTML elements to make them interactive without writing any JavaScript code!

Let's look at [the doc here](https://playhtml.fun/docs/capabilities/) to learn about `can-move`, `can-spin`, `can-grow`, and `can-toggle`. You can try adding these attributes to different HTML elements and see how they work!

### CSS for toggle

For `can-toggle`, we can customize the behavior using custom CSS.

<CodeDemo demo={<ColorToggleDemo />}>

```html
<style>
  #demo-color {
    background: #f3efe9;
    transition: background 0.3s ease;
  }
  #demo-color.clicked {
    background: #6cd97e;
  }
  #demo-color::before {
    content: 'off';
  }
  #demo-color.clicked::before {
    content: 'on';
  }
</style>
<button id="demo-color" can-toggle></button>
```

</CodeDemo>

For instance, you can swap between two images when toggled — like the [html starter template](https://github.com/spencerc99/playhtml/tree/main/templates/html-starter) does with a cat and dog. You can also combine these with other playhtml attributes.

<CodeDemo demo={<CatOrDogToggleDemo />}>

```html
<img id="catOrDog" src="images/cat.jpg" can-toggle can-move />
<style>
  #catOrDog {
    width: 200px;
  }

  #catOrDog.clicked {
    content: url('images/dog.png'); /* swaps to the dog image when clicked */
  }
</style>
```

</CodeDemo>

Or you can combine with [CSS transform](https://www.w3schools.com/cssref/css3_pr_transform.php), and make the element grow, spin, or move when toggled.

<CodeDemo demo={<ScaleToggleDemo />}>

```html
<button id="demo-scale" can-toggle>click me</button>

<style>
  #demo-scale {
    transform: scale(1);
  }

  #demo-scale.clicked {
    transform: scale(5);
  }
</style>
```

</CodeDemo>

To create a smooth animation between states, you can add CSS transition:

```html
<button id="demo-scale" can-toggle>click me</button>

<style>
  #demo-scale {
    transform: scale(1);
    transition: transform 0.3s ease; /* this part adds a smooth transition effect when the button is toggled */
  }

  #demo-scale.clicked {
    transform: scale(5);
  }
</style>
```
