### Let's create a web ring together!

What is a [web ring](https://en.wikipedia.org/wiki/Webring)? A web ring is a collection of websites that are linked together in a circular structure. Each site in the ring has a link to the next site, creating a continuous loop.

![A diagram of a web ring](/images/Webringwork.png)

When the internet was first created, Tim Berners-Lee created a rule for web servers: every folder needed a default homepage named `index.html`. He borrowed the word "index" from the back of a library book, where instead of looking at a confusing, cold list of raw computer files, visitors were greeted by a warm, curated table of contents.

If there's no `index.html` file in a folder, the web server will display a list of all the files in that folder.

```shell
/var/www/public_html/
├── images/
├── notes.txt
└── project_v1_final.html
```

As the web grew exponentially in the mid-90s, the exact same problem emerged at a global scale. The internet was now full of millions of isolated `index.html` files, but there was no "master index" connecting them. Search engines like Yahoo! were trying to build hand-curated, top-down directories, but they couldn't keep up with the explosion of personal homepages.

The webring solved this by turning the entire web into a collaborative directory. It took separate, isolated websites and stitched their `index.html` pages together into a decentralized loop.
