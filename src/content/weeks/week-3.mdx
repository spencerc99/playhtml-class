## Examples

### Example 1: a shared guestbook

A guestbook is a list of messages that everyone adds to and that sticks around between visits. That's exactly the "render a list from data you own" case from last week, so we reach for `can-play` with a `view`:

```html
<div can-play id="guestbook"></div>
<script type="module">
  import { html, playhtml, repeat } from 'https://unpkg.com/playhtml';

  playhtml.init();

  playhtml.register('guestbook', {
    defaultData: { messages: [] },
    view: ({ data, setData }) => {
      const leaveNote = (event) => {
        event.preventDefault();
        const input = event.target.querySelector('input');
        const message = input.value.trim();
        if (!message) return;
        setData((draft) => {
          draft.messages.push(message);
        });
        input.value = '';
      };

      return html`
        <form @submit=${leaveNote}>
          <input placeholder="leave a note..." />
          <button type="submit">Leave note</button>
        </form>
        <ul>
          ${repeat(
            data.messages,
            (message, index) => index,
            (message) => html`<li>${message}</li>`,
          )}
        </ul>
      `;
    },
  });
</script>
```

`defaultData` is the data the guestbook starts with (an empty list of messages), `setData` adds to it, and the `view` re-renders the list for everyone whenever a note is left. Because the messages are persisted, the guestbook fills up over time instead of resetting on refresh.

### Example 2: start with seeded notes

An empty guestbook can feel intimidating — nobody wants to be first. You can seed it with a few prompts by making them the starting value in `defaultData`:

```html
<div can-play id="guestbook"></div>
<script type="module">
  import { playhtml } from 'https://unpkg.com/playhtml';

  playhtml.init();

  const starterNotes = [
    'What makes this place feel welcoming?',
    'What sounds should live here?',
    'What should visitors be able to leave behind?',
  ];

  playhtml.register('guestbook', {
    defaultData: { messages: starterNotes },
    // ...same view as above
  });
</script>
```
